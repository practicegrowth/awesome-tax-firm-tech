# Evaluation worksheet index

These vendor-neutral worksheets help tax, CPA, accounting, bookkeeping, and tax-resolution firms evaluate a defined technology workflow. They are not product recommendations, implementation instructions, or tax, legal, accounting, compliance, or security advice. Use current primary sources, exact vendor documentation, firm policies, and appropriate professional advice for the decision at hand.

## Use the same decision record every time

Each worksheet is designed to leave a durable record. Capture the workflow scope, accountable owner, product or service under review, exact URLs and dates for provider evidence, representative test results, unresolved risks, commercial assumptions, and an explicit decision: **adopt for the defined workflow**, **extend with specific controls**, or **stop**.

Keep official-system steps, firm-owned decisions, and provider-supported capabilities distinct. A tool's presence in this repository does not establish its current capabilities, security posture, integrations, authorization status, or suitability for a particular client matter.
